# fixtures/minimal — эталонный мини-проект

Это **спецификация формата в исполнимой форме**: единственное место, где формат из ADR-0002/0005
записан целиком, а не по частям. Наполнена в A2 по находке RT-01 m6 (каталог существовал пустым,
а на фикстурах стоит вся верификационная история: AC4, AC4-b, AC6, blast-radius, тест корректности
кэша, SP-4).

* **Язык контента — английский** (Charter V12, rev3 от 2026-08-21). Это касается прозы
  `source/*.md` и контентных полей `publish.yaml` (`title`, `descriptionTemplate`). Комментарии
  в YAML, этот README и `provenance.note` остаются русскими: по V12 меняется язык **контента**,
  а не язык документации. Поля `language`/`locale` в схемах **не заводятся** — русский не
  планируется, и задел под второй язык был бы ровно тем, что V12 закрывает.
* Провайдер — только `tts:mock@1` (ADR-0010 §7): ни сети, ни ключей API, ни денег.
* 1 глава, 2 сцены, 7 абзацев, 3 картинки, музыкальная подложка; ~~все четыре маркера формата
  (`[beat:]`, `[pause:]`, `[say:]`, `[img:]`) встречаются хотя бы раз~~ *(изменено: RM2,
  2026-08-22, дрейф `docs/roadmap.md` §9 п. 9)* — **все семь позиций таблицы ADR-0002 §2**
  встречаются хотя бы раз, плюс восьмая строка таблицы (участок **без маркера**, где тишина
  берётся из дефолтов T8):

  | # | позиция таблицы ADR-0002 §2 | где в фикстуре |
  |---|---|---|
  | 1 | `[beat: name]` | `b:reveal`, `b:count`, `b:close` |
  | 2 | `[pause: Nms]` **на границе абзаца** (не режет чанк, **не стоит денег**) | `[pause: 600ms]`, `[pause: 400ms]` |
  | 3 | `[pause: Nms]` **внутри абзаца**, между предложениями (режет чанк на два, **стоит денег**) | `[pause: 250ms]` в первом абзаце сцены `intro` — **добавлено RM2** |
  | 4 | `[say: display \| spoken]` | `[say: 200 \| two hundred]`, `[say: “waiting” \| waiting]`, `[say: 14 \| fourteen]` |
  | 5 | `[img: alias]` | `harbour`, `ledger`, `sea` |
  | 6 | `[emph]` — **чисто визуальный** маркер, голосовой эмфазы в v1 нет (ADR-0010 §10) | перед словом `cost` в последнем абзаце — **добавлено RM2** |
  | 7 | `# chapter:` / `## scene:` | `# chapter: main`, `## scene: intro`, `## scene: turn` |
  | 8-я строка | *(нет маркера)* — тишина из дефолтов | межабзацные границы внутри обеих сцен |

  **`UNKNOWN`, входящий в позицию 6:** ADR-0002 §2 нормирует сам маркер `[emph]` («любое
  место», текст в TTS не идёт, якоря не создаёт), но **не нормирует его область действия**
  (одно слово? до конца предложения? парный маркер?). Фикстура ставит его непосредственно
  перед словом, к которому он относится — по единственному прецеденту в репозитории
  (`[img: alias]` перед предложением, к которому относится). Правило scope здесь **не
  формулируется**: это потребовало бы правки нормативной таблицы ADR-0002 §2, то есть
  отдельного решения владельца. Долг записан в
  [docs/spikes/rm1-closure.md](../../docs/spikes/rm1-closure.md).
* `anchors.lock.jsonl` отсутствует до первого `vpe parse` — его пишет CLI, и он появится
  в фикстуре первым же коммитом после запуска лексера.
* Проект **ещё не рендерится** — это цель. Всё дальнейшее строится так, чтобы он собрался.
* `voice/takes/` и `.store` пусты: дубли появляются при первом `vpe voice sync` на mock-провайдере,
  и первый же take-файл станет частью фикстуры (тогда `store.lock` перестанет быть пустым).

## Что этой фикстурой проверяется

| Проверка | Как |
|---|---|
| AC1 (минимальная форма) | проза + режиссура + 3 ассета → Timeline |
| AC3 / blast-radius | правка одного слова в `01-intro.md` ⇒ ровно один промах `voiceKey` |
| AC4 / AC4-b | рендер дважды на `profiles/render.ac4.yaml` |
| AC5-a | арифметика привязок и групп субтитров |
| AC6 | снимок этого каталога в `fixtures/legacy/v1/` **в том же коммите**, что и первый бамп схемы |
| Сегментация (C4/T8) | ассерт «сегментов ≥ 6» — граница каждой сцены и каждого абзаца является кандидатом |
| Линт прозы (D2 §3) | `[say:]` покрывает цифру (`200`, `14`) и типографские кавычки (`“waiting”`); цифр в прозе нет |
| Полнота формата (ADR-0002 §2) | все семь позиций таблицы маркеров плюс участок без маркера — таблица выше |
| Цена `[pause:]` (m1) | обе позиции присутствуют: на границе абзаца — бесплатная, внутри абзаца — платная (делит чанк на два) |
| Язык контента (V12) | в `source/*.md` и в `title`/`descriptionTemplate` нет кириллицы (инвариант V13) |
| Правило A1 (M1) | в `direction/` и `overrides/` нет ни одной ссылки `w:` |

## Чего здесь сознательно нет

`lexicon.yaml` (удалён, C1), `*.quarantine.jsonl` (карантина в v1 нет), `gridPoint` в режиссуре
(валидатор отвергает, M5), реактивных под музыку шаблонов (в v1 не строятся, M4).

`voice/roles.yaml` (семейство `voice-roles/1`, решение владельца 1 от 2026-08-22) — тоже
сознательно нет: пресеты ролей нужны там, где темп голоса меняется между сценами, а это
требование рецепта `fixtures/reference` (§6.2 roadmap) и задача `A-02`. `minimal` остаётся
минимальным; семейство заведено в ADR-0005 §1, а не здесь.

**Профили (после RM2, 2026-08-22).** Их четыре, и связь «имя файла ↔ `profileId`» записана
в ADR-0005 §1: `render.final.yaml` → `final`, `render.draft.yaml` → `draftHalf`,
`render.ac4.yaml` → `ac4`. Гейт V13 снимается только на `final` (N = 10) и `draftHalf` (N = 3);
`render.ac4.yaml` — **полный прогон фикстурного проекта**, а не проверка шаблона
(Charter AC4 rev5, решение владельца 12).
