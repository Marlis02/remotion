# SP-2 — «Alignment на английском: тождество, здоровье, границы»

Спайк из `docs/architecture/core.md §16`. **Блокирующий**: до его результатов ADR-0003 и ADR-0010
не закрыты в частях T7, §1, §3, §6, а пометка-вопрос Charter V5 (линт-запрет цифр) висит открытой.

**Спайк только отвечает на U-вопросы.** ADR и Charter он не меняет — решения принимает владелец
отдельным коммитом.

**Код этого каталога — одноразовый**, кроме `mock.mjs` и `mock.test.mjs`: они написаны по
интерфейсу ADR-0010 §7 и переезжают в пакет провайдеров. Остаются **артефакты замеров**
в `results/`.

```bash

./run.sh estimate.mjs         # бесплатно: смета всех платных вызовов
./run.sh --test mock.test.mjs # бесплатно: блок 8, 18 тестов
./run.sh lint-digits.mjs      # бесплатно: блок 9

./run.sh block1.mjs           # платно: блок 1 (28 вызовов, 1215)
./run.sh analyze1.mjs         # бесплатно: разбор блоков 1 и 2 по raw/
./run.sh acoustic.mjs         # бесплатно: акустический лид-ин/хвост
./run.sh block2b-nopunct.mjs  # платно: 2 вызова, 69
./run.sh block3.mjs && ./run.sh analyze3.mjs   # платно: 5 вызовов, 221
./run.sh block4.mjs           # платно: 4 вызова, 2929
./run.sh block5.mjs           # платно: 7 вызовов, 599
./run.sh block6.mjs           # платно: 3 вызова, 192
./run.sh block7.mjs           # платно: 1 вызов, 76 — нужно право ключа

./run.sh finalize-machine.mjs # бесплатно: итог расхода в machine.json
```

**Досъёмка SP-2b** (боевой голос, тариф Creator). Режим голоса выбирается флагом
`--voice=env` (боевой из `ELEVENLABS_VOICE_ID`, **дефолт**) или `--voice=premade` (Daniel).

```bash
./run.sh machine-sp2b.mjs     # бесплатно: тариф, лимит, голос -> machine.json.snapshot_sp2b
./run.sh block1-prod.mjs      # платно: блок 1, 28 вызовов, 1212 code points
./run.sh analyze1-prod.mjs    # бесплатно: разбор блоков 1 и 2 по raw/*-prod.json
./run.sh acoustic-prod.mjs    # бесплатно: акустический лид-ин/хвост (метод SP-2 не менялся)
./run.sh t7-prod.mjs          # бесплатно: сколько тишины реально снимает T7
./run.sh block3-prod.mjs && ./run.sh analyze3-prod.mjs   # платно: 5 вызовов, 221
./run.sh block7-prod.mjs      # платно: 1 вызов, 76 — нужно право ключа (пока 401)
./run.sh block4-2700-prod.mjs # платно: 1 вызов, 2689 — долг 4
./run.sh compare-prod.mjs     # бесплатно: построчная проверка voice-and-tier.md §4.1
./run.sh billing-prod.mjs     # бесплатно: сверка расхода по окнам usage/character-stats
./run.sh finalize-sp2b.mjs    # бесплатно: итог расхода в snapshot_sp2b
```

> **Нельзя запускать после досъёмки:** `acoustic.mjs`, `analyze1.mjs`, `analyze3.mjs`.
> Они берут дубли по префиксу `b1-`/`b3-`, подмешали бы файлы `-prod` в статистику Daniel и
> перезаписали бы `raw/block2-acoustic.json`, `raw/block1-block2.json`, `raw/block3-pause.json`.
> Для боевого голоса есть их `-prod`-двойники.

Скрипты **идемпотентны**: если `results/raw/<id>.json` уже есть, вызов пропускается и деньги
не тратятся. Перед каждым платным вызовом `assertBudget()` падает, если вызов выводит спайк
за 7000 символов. У досъёмки свои ворота — `assertProdBudget()` из `lib/prod.mjs`, лимит 5000,
и считает она **только** дубли с суффиксом `-prod` и **по code points**.

## 4. Гигиена секретов

* Ключ и голос читаются **только** из `process.env` (`run.sh` передаёт `--env-file`);
  ни один скрипт не открывает `.env` сам.
* Любая строка, уходящая в лог или в файл, проходит через `redact()`: ключ и боевой voice_id
  заменяются на `<API_KEY>` / `<VOICE_ID>`.
* В `machine.json` записано **имя** голоса из `GET /v1/voices/{id}`, а не id.
* Публичный id premade-голоса, на котором снят спайк, записан открыто — он есть в документации
  ElevenLabs и нужен для воспроизводимости.
* `out/` целиком в `.gitignore`: там PCM, WAV и нетронутые ответы с `audio_base64`.

## 5. Итог одной строкой

Тождество `alignment` к входу держится **28/28**, массив приходит в **code points**, при `off`
провайдер **не трогает числа, даты, деньги и проценты**, деградации alignment нет **до 1514
символов / 113.7 с**, пауза падает на знак и пробел и в слова **не попадает**. Одно опровержение:
**T7 снимает хвост, но не снимает лид-ин** — по таймкодам его нет, акустически он есть и равен
медианным 100 мс, что больше всего бюджета AC5.

## 6. Досъёмка SP-2b — итог одной строкой

Тариф Creator, боевой голос `Michael C. Vincent`, 34 платных вызова, 4122 code points
отправлено, **2268 списано** (ставка тарифа: `round(codePoints × 0.55)` покалльно; на Free было
×1.00). Структура alignment **голосом не определяется** — тождество 28/28, code points, `start[0]=0`,
пауза на знаке и пробеле, `normalized_alignment` совпал с Daniel побайтово. Все миллисекунды
разошлись: Michael быстрее на 13 %, хвост короче, а **ранжирование пауз по знакам не переносится**
(`.`/`,`/`;` дают одну и ту же паузу) — значит гарантированная пауза только через `[pause:]`.
**T7 воспроизвёлся на втором голосе:** таймкоды говорят 0, аудио — 95 мс. Долг 4 закрыт:
2689 симв. / 155.4 с, `uniqueTimestampRatio` 1.000. Долг 1 (словарь) закрыть не удалось — 401.
