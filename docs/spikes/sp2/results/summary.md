## Блок 1 — тождество и единица массива (U4, U16), 28 строк, 1215 симв.

Обе строки с `ratio < 1` — строки с эмодзи, и обе по одной причине: **непроизносимые code points
получают интервал нулевой длины**, и их старт совпадает со стартом соседа.

| строка | элементы с нулевой длительностью | `ratio` | `maxEqualRun` |
|---|---|---|---|
| `b1-23-emoji` | пробел после `🚢` | 0.976 | 2 |
| `b1-27-emoji-tone` | модификатор тона `🏽` и пробел после него | 0.956 | 3 |

У всех 26 строк без эмодзи `ratio` = 1.000 и `maxEqualRun` = 1.

**Единица массива `alignment.characters` — code points.**

| строка | UTF-16 units | code points | графемы | длина массива |
|---|---|---|---|---|
| `b1-21-cafe-nfd` (`cafe` + U+0301) | 45 | 45 | 44 | **45** |
| `b1-23-emoji` (U+1F6A2) | 43 | 42 | 42 | **42** |
| `b1-27-emoji-tone` (U+1F44D U+1F3FD) | 47 | 45 | 44 | **45** |

Совпало с длиной массива: UTF-16 — 26/28, code points — **28/28**, графемы — 26/28.

### U16 — что делает `apply_text_normalization: "off"`

`alignment` равен входу побайтово у всех 28 строк. `normalized_alignment` отличается всегда:
минимум — обрамляющие пробелы (`1/1` у всех 28 строк), у 8 строк — ещё и подстановки.

| класс | пример | в `alignment` | в `normalized_alignment` (без обрамляющих пробелов) |
|---|---|---|---|
| сокращение с точкой | `Dr. Smith` | дословно | **дословно** |
| год цифрами | `in 1793` | дословно | **дословно** |
| порядковое | `the 3rd of May` | дословно | **дословно** |
| порядковое | `21st century` | дословно | **дословно** |
| деньги | `$5` | дословно | **дословно** |
| процент | `5%` | дословно | **дословно** |
| дата | `03/04` | дословно | **дословно** |
| разряды | `1,000,000` | дословно | **дословно** |
| десятичная дробь | `3.14` | дословно | **дословно** |

Что `normalized_alignment` всё же переписывает (8 строк из 28):

| вход | становится | строка |
|---|---|---|
| `’` U+2019 | `'` U+0027 | `b1-12-apos-typ` |
| `—` U+2014 | `--` (два дефиса) | `b1-15-emdash` |
| `–` U+2013 | `-` U+002D | `b1-16-endash` |
| `“` `”` U+201C/U+201D | `"` U+0022 | `b1-17-curly` |
| `…` U+2026 | `...` (три точки) | `b1-18-ellipsis1` |
| ` ` U+00A0 (NBSP) | ` ` U+0020 | `b1-22-nbsp` |
| `🚢` U+1F6A2 | **удалён** | `b1-23-emoji` |
| `👍🏽` U+1F44D U+1F3FD | **удалён** | `b1-27-emoji-tone` |
