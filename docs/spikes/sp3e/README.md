# SP-3e — моушн-бенч: графики, счётчики, stagger на обоих рендерерах

Спайк **решений не принимает**. Он отвечает на один вопрос: **проходит ли слой
моушн-графики гейт «N прогонов дают один файл» на каждом из двух рендереров и
сколько он стоит по кадрам/с.** Решение по рендереру принимает владелец.

SP-3, SP-3c и SP-3d мерили одну и ту же композицию — картинка + Ken Burns +
субтитры + затемнение. Charter с первого дня требует слой моушн-графики
(инфографика, диаграммы, анимация элементов), а SP-3d показал (§1.2, §6), что
детерминизм зависит от **стиля композиции**, и единственный надёжный признак —
«N прогонов = один файл». Здесь этот гейт применён к моушн-композиции.

## Композиция

10 секунд, 1080×1920, 30 fps, 300 кадров, немая, без сети, шрифт
`DejaVuSans-Bold.ttf` локально, фон — сплошной цвет (`backdrop.jpg` намеренно нет:
его ресайз уже измерен в SP-3 и здесь был бы только шумом).

Пять элементов, каждый — детерминированная функция номера кадра, каждый виден в
свой отрезок:

| # | элемент | отрезок | кадры |
|---|---|---|---|
| 1 | столбчатая диаграмма, 6 столбцов, отскок, сдвиг старта 4 кадра, подписи | 0–4 с | 0–120 |
| 2 | счётчик 0 → 1793, 160 px, моноширинная раскладка цифр | 1–3 с | 30–90 |
| 3 | линейный график: путь из 40 точек, прорисовка слева направо, градиентная заливка | 3–7 с | 90–210 |
| 4 | stagger-сетка: 200 кружков, волна по диагонали, затем одновременная смена цвета | 5–8 с | 150–240 |
| 5 | SVG-морфинг: один путь, 10 узлов, круг → звезда → обратно | 7–10 с | 210–300 |

Все значения (высоты столбцов, 40 точек графика, геометрия сетки и морфинга) —
константы в **общем** [`data.json`](data.json). Никакого `Math.random`/`Date.now` (V8).

## Что здесь лежит

| путь | что это |
|---|---|
| `data.json` | все константы композиции; читается обоими рендерерами |
| `src/remotion/` | React: `useCurrentFrame` + `interpolate`/`spring`; `shared.ts` — геометрия |
| `src/hyperframes/index.html` | HTML + GSAP-таймлайн; **генерируется**, руками не правится |
| `gen-hyperframes.mjs` | генератор HTML из `data.json` (разметка 6 столбцов, 200 кружков, путь графика) |
| `run-remotion.mjs` | один прогон Remotion отдельным процессом + проверки над сегментом |
| `run-hf.mjs` | один прогон HyperFrames отдельным процессом (адаптация `sp3c/run-one.mjs`) |
| `matrix.mjs`, `jobs/matrix.json` | драйвер матрицы: таймаут на прогон, дедлайн, append в `results/progress.jsonl` |
| `hfenergy.mjs` | ВЧ-энергия кадра 150 по методу SP-3d §1.2 |
| `determinism.mjs` | сведение гейта по группам + PSNR на расходящихся парах |
| `where.mjs` | ГДЕ расходятся прогоны: различающиеся кадры раскладываются по окнам пяти элементов |
| `loc.mjs` | сколько строк кода стоит каждый элемент на каждом рендерере (границы — комментарии в коде) |
| `lib/summary.mjs` | пересборка `results/summary.md` из `results/raw` |
| `machine.mjs`, `fixture.mjs`, `hostload.sh` | окружение, sha256 композиций, журнал загрузки хоста |
| **`results/`** | **все измерения — остаются в репозитории** |

## Приборы

Взяты **импортом** из SP-3 и SP-3c, не копированием: `sp3/lib/media.mjs`
(framemd5, ffprobe, keyframes, sha256, PSNR), `sp3/lib/proctree.mjs` (пик RSS
дерева процессов), `sp3/lib/sysinfo.mjs`, `sp3/lib/profiles.mjs` (рецепт
энкодера блока D), `sp3c/bin/{ffmpeg,ffprobe}` (статические сборки; системного
ffmpeg на машине нет). Их файлы не правились: у SP-3e свой `lib/summary.mjs`,
чтобы вызов не переписал `results/` чужого спайка.

`sp3e/node_modules` — символьная ссылка на `sp3/node_modules`: пакеты Remotion
и Chrome не дублируются.

## Как повторить

```
cd docs/spikes/sp3e
export PATH=$HOME/.nvm/versions/node/v25.6.1/bin:$PATH
node gen-hyperframes.mjs            # HTML из data.json
node fixture.mjs && node machine.mjs
node matrix.mjs jobs/matrix.json     # 26 прогонов матрицы задания
node matrix.mjs jobs/control.json    # 9 контрольных на композициях SP-3/SP-3c
node hfenergy.mjs && node determinism.mjs && node where.mjs && node loc.mjs
node lib/summary.mjs
```

Chrome для Remotion должен быть скачан **заранее** (`ensureBrowser` кладёт его в
`.remotion/`, ~200 МБ, в git не идёт): в самих прогонах загрузка запрещена и валит
прогон — это V9. `sp3/node_modules` должен быть восстановлен (`npm install` в `sp3`);
версии в `sp3/package.json` пришпилены точно.
