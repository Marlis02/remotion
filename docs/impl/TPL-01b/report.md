## 2. Измерение §3.1 — главное число

Владелец заменил `work/ct-test-1` (его на этой машине нет и быть не должно) на
`examples/ai-test-1`, который здесь собирается. Порядок соблюдён дословно.

| прогон | режиссура | стенка | рендеров | sha256 `final.mp4` |
|---|---|---|---|---|
| холодная (кэш пуст) | `params` числами | **221.8 с** | 3 (три промаха) | `83799253fa9a…` |
| прогретая | `params` числами | **1.65 с** | **0** (три попадания) | `83799253fa9a…` |
| **на пресетах** | `preset:` ×7, `params` не осталось | **1.75 с** | **0** (три попадания) | `83799253fa9a…` |

Значения кэша тоже те же — `8bd8d24c0a25…`, `d4de25109fd6…`, `92eafa8b40cc…`; `bundle.hash`
всех трёх сегментов не сдвинулся. `.cache/segment/final` — 39 MiB.

**Что именно этим доказано.** Попадание кэша = равный `segmentKey`; `segmentIrHash` — одно из
семи его слагаемых, и единственное, куда `params` могут попасть. Равный ключ при переписанной
режиссуре означает, что **IR пресета не заметил**: в него уехали те же байты `params`. Ускорение
×134 к делу не относится — оно измерение `CACHE-01`, здесь важно ЧИСЛО РЕНДЕРОВ.

**Чего это НЕ доказывает.** Что пресеты «правильные»: равенство байтов есть равенство байтов, и
если бы я списал числа неверно, кэш промахнулся бы — то есть охранник ловит именно эту ошибку.
И не доказывает `draftHalf`: он не снимался (чужая причина — долг №183 закрыт вариантом (а), но
профиль здесь просто не запрашивался).

Таблица «ноут» дописана в `docs/impl/CACHE-01/report.md` — новым разделом §4 перед разделом
`ct`, вместе с третьим прогоном (на пресетах), которого у `PROD-01` не было. Два независимых
измерения «минуты → секунды» вместо одного: ×134 здесь, ×146 на `ct`.

## 4. Дифф `packages/schema` — по разрешению владельца

Закрытая зона; тронуто ровно одно место — запись с `template` в
`packages/schema/src/families/direction.ts`:

```diff
     template: identifier(),
+    /** Имя пресета … Разворачивает пресет КОМПИЛЯТОР до `paramsSchema` … */
+    preset: identifier().optional(),
-    params: z.record(z.string(), JsonValueSchema),
+    params: z.record(z.string(), JsonValueSchema).optional(),
   })
-  .strict();
+  .strict()
+  .refine((record) => record.preset !== undefined || record.params !== undefined, {
+    message: 'запись шаблона обязана нести `preset` либо `params` …',
+  });
```

Три проверки, снятые до правки, чтобы она не оказалась той, «которая тянет за собой ещё три»:

* **`.refine` у члена `discriminatedUnion` в zod 4.4.3 работает** — прогон: union строится,
  запись без обоих даёт `custom`-issue с моим текстом, ветка `voice` не задета. `FACT`.
* **`migrate.ts` слова `direction` не содержит**, `canonical/json.ts` — общий писатель
  отсортированного JSON, про семейства не знающий ⇒ ни миграции, ни канонической формы правка
  не тянет. Стоп по §0 задания не наступает. `FACT`.
* **`.strict()` цел** — охраняется тестом (`packages/schema/test/direction-preset.test.ts`).

Побочная правка ВНЕ схемы, которую эта потянула: `TemplateParams` в `core-model` выводился как
`Extract<Direction['records'][number], { params: unknown }>['params']`, а на необязательном поле
`Extract` даёт `never` (TypeScript требует, чтобы свойство присутствовало). Дискриминант заменён
на `template` — тип по-прежнему ВЫВОДИТСЯ из схемы, а не объявляется второй раз.

| № | охранник | чем закрыт |
|---|---|---|
| 1 | пресет == ручные `params` | измерение §2 (3/3 попадания, равный sha) **плюс** юнит «контракт побайтово равен» (`compile/test/template-presets.test.ts`) |
| 2 | каждый `presets/*.json` проходит `paramsSchema` | `attachPresets` — на ЗАГРУЗКЕ каталога; вычисляется по папкам, списка имён нет. Пробы — `templates-spec/test/presets.test.ts` (чужая схема, кривой `easing`, пустой `note`, лишнее поле, имя не по грамматике, папка без спека) |

| 3-бис | `preset` у шаблона без пресетов → отказ | юнит (живого шаблона без пресетов сегодня нет — оговорено в транскрипте) |
| 4 | наложение по верхнему уровню | юнит: `to` авторский ЦЕЛИКОМ, `from`/`easing` из пресета, `to.x` пресета не просочился |
| 5 | ни `preset`, ни `params` → отказ схемы | транскрипт, проба 2 + `schema/test/direction-preset.test.ts` |
| 6 | имени пресета нет ни в seed, ни в хэше (**D2**) | юнит «в контракте нет строки `drift-right`» — проверка по ВСЕМУ значению, а не по названным полям; плюс §2 |
| 7 | 12 запросов побайтно, `bundle.hash` те же | §5, 44/44 |
| 8 | полный прогон 0 failed | §8 |

`FACT` по вопросу «входит ли `preset` в хэш/seed»: **не входит и не может**. `seedOf` берёт
четыре входа (`chapterId`, `sceneId`, `recordId`, `purpose` + `seedRoot`) и охраняется типом,
тестом и грепом `d2-seed-inputs`; `segmentKey` — семь слагаемых, текста режиссуры среди них нет;
`compositionHash` считается по перечню каталога композиции, куда `presets/` не копируется;
`engineFingerprint` — версии не-`@vpe` зависимостей. Единственное место, где переход виден
числом, — `BuildRecord.inputs[]` (sha прочитанных файлов), и он ни в один ключ не входит.
