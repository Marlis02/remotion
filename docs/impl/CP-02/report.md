## 3. Измерение потолка (`FACT`, а не `INFERENCE`)

Скрипт — [`measure-font.mjs`](measure-font.mjs) рядом с отчётом: парсер таблиц `head`, `OS/2`,
`hhea`, `hmtx` и `cmap` формата 4, без зависимостей. **Это ОДНОРАЗОВЫЙ зонд, а не тест:** шрифта
в репозитории нет (он берётся из системы), и в прогон `vitest` файл не входит.

`FACT` (`/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf`, DejaVu Sans Bold 2.37):

| Величина | Значение |
|---|---|
| `head.unitsPerEm` | **2048** |
| `OS/2.xAvgCharWidth` | **1173** = 0.5728 em |
| средний advance по display-тексту фикстуры (853 символа) | **1176.9** = 0.5746 em |
| полоса `width − safeAreas.left − right` | `1080 − 60 − 60` = **960 px** |
| самая широкая группа-кандидат ≤ 21 символа при кегле 72 | «warehouses held goods» = **957 px** |
| самая широкая ≤ 22 символов | «The harbour warehouses» = **1008 px** |

Отсюда **21** — наибольшее N, при котором ни одна группа этой фикстуры не выходит за полосу при
кегле 72. Номинал `xAvgCharWidth` и фактический средний по контенту сходятся в пределах 0.3 %,
то есть число не подогнано под один текст.

`INFERENCE` и остаточный риск (долг №125, дословно в `DEBTS.md`): потолок в символах —
**прокси ширины**. Бюджет при 21 символе — 960 / (21 · 72) = **0.6349 em/символ**; p90 ширины
символа среди кандидатов групп фикстуры — 0.6753 em, и превышают бюджет только КОРОТКИЕ
однословные кандидаты («When» — 0.8013 em/символ), чья полная ширина мала. Строка из 21
широкой буквы дала бы ~1210 px; на этом контенте таких нет, гарантии это не даёт.
Пересмотр — вместе со шрифтом, глазами (`TS-01`/`H-07`).

## 5. Две находки сессии

### 5.1. Дефект, пойманный собственным тестом детерминизма

`anchorIdByToken` (`@vpe/voice`) соединяет токены с якорями **zip'ом по порядку входного
массива**. Тест «перестановка входов не меняет дамп» уронил его сразу:
`токен №1 разбора и якорь №1 ledger'а описывают разные слова: у токена «The», у якоря «cost.»`.
Критерий готовности `CP-01` был бы нарушен. Починено каноническим порядком, который стадия
якорей УЖЕ посчитала — `AnchorTimes.ordinalById` (`(глава, сцена, ordinal слота)`); третьей
сортировки в репозитории не заведено.

### 5.2. Дыра в собственном охраннике, найденная протоколом нарушений

Нарушение 4 («группа проходит через границу речевого клипа») **не уронило ни одного теста**.
Причина: на фикстуре КАЖДЫЙ речевой клип кончается токеном с точкой, поэтому группу на границе
клипа закрывало правило конца предложения, а проверка клипа была замаскирована. Заведён тест
«граница речевого клипа держит группу ДАЖЕ КОГДА правило предложения молчит» —
`tokensPerGroupMin = tokensPerGroupMax` глушит правило предложения, потолок поднят до 200, —
плюс **контроль предмета**: в выборке обязаны быть группы, где точка стоит не на последнем
слове, иначе тест зелен на пустоте. Попытка 2 того же нарушения покраснела:
`«years running. Ships» вышла за клип 72xh5eni6aev6aqz: expected 97080 to be ≤ 84480`.
Обе попытки — в [`violation-transcript.txt`](violation-transcript.txt), первая НЕ стёрта.

## 6. Кандидаты в правку ADR-0003 «Субтитры (M6)» (ADR не правил)

**Первый абзац — взамен строки «минимум … обеспечивается уменьшением числа слов (3 → 2 → 1)».**

> Группа набирается жадно, слева направо, до `tokensPerGroupMax` слов, пока строка не превысила
> потолок символов и пока не кончился речевой клип. Потолок символов дробит группу числом слов
> (3 → 2 → 1) и **побеждает** минимум длительности: строка, не влезающая в полосу, хуже короткой
> группы. `minGroupDurationFrames` — **порог записи в отчёт сборки**, а не цель: группа, которая
> при максимуме слов всё равно короче него, принимается как есть и попадает в отчёт. Увеличить
> её нечем — число слов уже максимально, а сдвиг запрещён (T10).

**Основание (измерено, `CP-02`).** Прочтение «расти, пока короче минимума» даёт на
`fixtures/minimal` **113 групп: 60 однословных, 53 двусловных, ни одной из трёх слов**, самая
длинная строка **13 символов** — то есть потолок символов, принятый решением владельца
2026-08-23, не срабатывает НИ РАЗУ, а диапазон «1–3 слова» вырождается в «1–2». Жадная набивка
даёт **58 групп** (до правила предложения) с максимальной строкой 21. При одном и том же
стартовом токене жадная набивка даёт группу не короче ранней остановки, поэтому для минимума
ранняя остановка не добавляет ничего.

**Второй абзац — новое правило, которого в ADR нет (решение владельца 2026-08-26, вопрос 5).**

> Конец предложения закрывает группу: если display-форма последнего слова группы кончается на
> `.`, `!` или `?` (допускаются закрывающие кавычки и скобки после знака), следующее слово
> начинает новую группу. Правило слабее `tokensPerGroupMin`: пока слов в группе меньше минимума,
> оно молчит.

**Основание (измерено).** Пауза знака внутри речевого клипа — **9120 сэмплов = 380 мс**. Без
правила **4 группы** держали бы на экране первое слово следующего предложения всю эту паузу,
то есть зритель читал бы слово раньше, чем слышит его. Цена правила: групп **58 → 60**, из них
три однословные, **коротких по-прежнему 0**.

**Третий кандидат — комментарий фикстуры.** Строка `minGroupDurationFrames: 6  # группы не
сдвигаются; минимум — за счёт числа токенов (M6)` разошлась с принятым прочтением (б). Не
правил: разрешение промпта покрывало ровно три строки профиля. Долг №127.

## 8. Реестр инвариантов

**Два перехода `named → guarded`: T10 и T11. Счёт 40 → 42.**

* **T10** — для каждой из 60 групп `start == start(первого токена)` и `end == end(последнего)`;
  неперекрытие проверено и внутри клипа, и глобально; ни одна группа не выходит за свой клип.
  Показано падающим четырьмя способами.
* **T11** — два ассерта на трёх сетках (`30/1`, `60/1`, `30000/1001`): якорей `w:` в ledger
  **167 == 167** токенов документа; разрешённых во времени **166** = токены минус `absent`;
  плюс 1:1 — каждый разрешённый якорь ровно в одной группе. Клетка получила уточнение владельца
  «(в ledger, не во времени)».

Ни один охранник не удалён.

## 9. Известные ограничения

1. **Потолок — прокси ширины, а не ширина** (§3, долг №125). Компилятор шрифта не видит и видеть
   не должен: `compose` — чистая функция без диска.
2. **`Mr.`-класс сокращений** режет группу (долг №129). Своего правила границы предложения
   субтитры не заводят намеренно.
3. **Минимум длительности на `fixtures/minimal` не срабатывает** (коротких групп 0): mock
   медленный (`msPerChar: 55`). Ветка проверена синтетическим дублем с `msPerChar: 10`.
4. **Балансировка хвоста не делается** (долг №124): `tailSingletons` на фикстуре — 1.
5. **Порядок токенов в группе** — порядок ПРОЗЫ, а не измеренного времени. Если бы провайдер
   вернул перекрывающиеся интервалы, подсветка внутри группы поехала бы; тест монотонности
   подсветки это ловит, но правила «что делать» нет ни в одном ADR — предмета пока не было.
