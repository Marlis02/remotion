## 6. Находки — записаны, в дифф не вносились

1. **Расхождение номера параграфа roadmap.** Задание называет детальные подразделы `H-03`/`H-04`/
   `H-05` «§4.9» — фактически они лежат в **§4.8** (`### 4.8. renderer-hyperframes`, roadmap.md
   строки 981–1150); `§4.9` — это раздел `cli` (`L-01`…). Это же расхождение — во второй форме:
   задание относит фразу «Переводит в `guarded`: R14, K6» к «§3», но дословно эта фраза стоит
   только в §4.8 (строка 1046 до правки); компактная таблица §3 просто перечисляет `R14, K6` в
   колонке инвариантов без глагольной рамки. Правки внесены **по контенту** (там, где дословно
   стоит цитируемый текст), а не по указанному номеру параграфа — расхождение не помешало найти
   правильное место однозначным поиском.
2. **ADR-0006 §3, канонический список `engineFingerprint`** (блок `blake3(...)`, строки 187–196)
   по-прежнему называет «фактическая командная строка энкодера» восьмым слагаемым — тем же
   термином, который эта сессия убрала из **roadmap** (п. 12). Задание перечисляло эту правку
   только для roadmap («roadmap §4.9 `H-03`, состав ⊕»), не для ADR-0006, и пункты 1–15 её для
   ADR-0006 не называют — поэтому формула ADR-0006 **не тронута**. После этой сессии roadmap и
   ADR-0006 расходятся в описании состава отпечатка; расхождение существовало и до сессии
   (roadmap просто зеркалировал устаревший состав), но теперь стало явным, а не подразумеваемым.
3. **roadmap §3, строка `H-05`**, колонка «что»: всё ещё называет «ulimit RSS» (в отличие от
   исправленного §4.8). Задание указывало правку только для «§4.9» — компактная строка §3 в
   перечень пунктов 1–15 не входила, оставлена как есть.
4. **roadmap.md §4.8, `H-03`, бюллет «Почему нужен».** Строкой ниже правки п. 13 (в том же
   подразделе) стоит третья копия того же устаревшего обоснования R14 («версия Chrome не
   пришпилена самим пакетом — её выбирает `puppeteer`»), не тронутая заданием: пункты 1–15
   называют только ADR-0006 §3 (п. 10) и invariants.md R14 (п. 15) как места правки этой фразы.
   Оставлено как есть — тот же класс находки, что и п. 2/3 выше.
5. **Пункт 14, ярлык «RM…».** Задание просило пометку «сверх карты, RM…», не называя число.
   Готового прецедента `RM3` (или любого другого номера, продолжающего `RM1`/`RM2`) в документах
   проекта нет. Первая версия правки самовольно проставила `RM3` — это было **додумыванием
   неразрешённой развилки**, откачено: строка `CP-07` несёт только стандартную пометку `DOC-06`
   и прямой вопрос владельцу («точный ярлык — см. отчёт DOC-06»), без выдуманного номера серии.
   **Решение за владельцем**, если отдельный ярлык `RM*` для этой строки желателен.
