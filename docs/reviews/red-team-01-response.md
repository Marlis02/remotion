## Легенда решений


| Решение | Значение                                                                                                                              |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `fix`          | документы исправлены, находка закрыта                                                                        |
| `accept`       | риск принят осознанно, причина записана в соответствующий ADR (раздел «Риски») |
| `reject`       | находка отклонена с аргументом                                                                                     |
| `defer`        | исправление отложено до конкретного спайка/этапа (указать, до какого)               |
