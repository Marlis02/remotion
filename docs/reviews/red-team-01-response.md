# Реакция на RT-01 (Red Team Review ядра)

* **Статус:** заполнено в сессии A2 (ЭТАП 3 → ЭТАП 4 по `00-PROCESS.md`), 2026-08-19.
* **Вход:** `docs/reviews/red-team-01.md` (27 находок + overengineering audit + процессные замечания).
* **Правило:** ни одна строка не остаётся пустой. «Принять риск» — законный ответ; отсутствие ответа — нет.
* **Ревью не редактировалось.** `red-team-01.md` — подписанный артефакт независимой сессии; он
  оставлен дословно, включая старую нумерацию спайков. Соответствие нумерации — в §4 этого файла.

## Легенда решений

| Решение | Значение |
|---|---|
| `fix` | документы исправлены, находка закрыта |
| `fix (fallback)` | принят **fallback** из ревью, а не основная Prevention — потому что он дешевле и убирает класс целиком |
| `accept` | риск принят осознанно, причина записана в соответствующий ADR |
| `defer` | исправление отложено до конкретного спайка/этапа (указано, до какого) |
| `reject` | находка отклонена с аргументом |

**Итог по 27 находкам:** `fix` — 24, `fix` частично + `defer` остатка — 2 (M11, m3),
`defer` (решение владельца) — 1 (m7). `reject` — 0.
Отклонённых находок нет: ни одна из 27 не оказалась ложной.
