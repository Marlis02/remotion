# `@vpe/cli`

**Ответственность (карта ADR-0009):** парсинг аргументов, оркестрация стадий, вывод.
Единственный пакет, который знает про всех.

**Импортирует:** все семь пакетов монорепо; `hyperframes` — один из двух пакетов, которым это
разрешено (**M1**).
**НЕ импортирует / НЕ содержит:** доменной логики — ни модели, ни компиляции, ни ffmpeg-вызовов
(правило ADR-0009 Consequences, проверяется размером и ревью); `gsap` (**M6**);
`react`/`react-dom` (**M2**). Сеть в `cli` допускается **вне** рендера (ADR-0008), но не в
рендер-пути; охранник сети — **M4**.
