# `@vpe/cli`

**Ответственность (карта ADR-0009):** парсинг аргументов, оркестрация стадий, вывод.
Единственный пакет, который знает про всех.

**Импортирует:** все семь пакетов монорепо; `hyperframes` — один из двух пакетов, которым это
разрешено (**M1**).
**НЕ импортирует / НЕ содержит:** доменной логики — ни модели, ни компиляции, ни ffmpeg-вызовов
(правило ADR-0009 Consequences, проверяется размером и ревью); `gsap` (**M6**);
`react`/`react-dom` (**M2**). Сеть в `cli` допускается **вне** рендера (ADR-0008), но не в
рендер-пути; охранник сети — **M4**.

---

## Команды (`E-00`, 2026-08-29)

```
vpe template gate <id>@<N> --profile final|draftHalf --request <файл> --render-profile <файл.yaml>
                           [--gates-dir <кат>] [--run-root <кат>]
vpe template list [--gates-dir <кат>]
```

**`template gate`** — гейт детерминизма шаблона (Charter **V13**, ADR-0008 «Гейт → Процедура»):
N прогонов одной конфигурации (10 на `final`, 3 на `draftHalf`), две величины (`sha256` файла и
`framemd5` картинки), класс результата. **Запись `<id>@<N>.gates.json` создаёт только `PASS`** и
кладёт её РЯДОМ СО СПЕКОМ, в дерево исходников: коммитит её автор руками (решение владельца 5,
RM1 — ночного CI в v1 нет).

Три входа обязательны, и каждый закрывает свою дыру: имя — что проверяется; `--request` —
фикстура шаблона (каждый её клип обязан звать НАЗВАННЫЙ шаблон); `--render-profile` — полный
`pixelProfile` для энкодера (в запросе живут лишь три поля адаптера, **K4**), а его `profileId`
сверяется с `--profile`.

**Коды выхода:** `0` PASS · `1` договорный отказ · `2` вход не разобрался · `3`
`FLAKY-по-контейнеру` · `4` `FAIL` · `5` `error` («гейта не было»).

**`template list`** — таблица каталога «шаблон · версия · гейт · бюджет мс/кадр · класс
детерминизма · easing». Устаревание записей она НЕ проверяет и пишет об этом: вопрос про пару
(профиль, отпечаток, композиция) требует пробы окружения, а просмотр каталога обязан работать и
там, где движок не установлен.

**Часы читает ровно один файл пакета — `bin/vpe.ts`** (граница процесса, **D4**): `date` записи
гейта приезжает внутрь входом `now`. Охранник — `tests/lints/d4-clock-boundary.test.ts`.
