# `examples/vertical-v1` — вертикальное демо визуального языка v1

**Что это.** Настоящий проект движка, собираемый штатным `vpe build`, — не фикстура. Он
заведён задачей [`H-07`](../../docs/impl/H-07/report.md) ради DoD Charter §8 п. 5: «я лично
посмотрел результат глазами, для видео — **на телефоне**».

**Чем отличается от `fixtures/minimal`, и почему их два.** Фикстура — вход ОХРАННИКОВ: её
нельзя трогать ни символом, её ассеты — синтетические sha (`0000…0001`), а картинка в кадре —
шахматка 32×32. Смотреть на неё глазами бессмысленно. Здесь наоборот: три настоящих
фотографии public domain, настоящий вариативный шрифт, три сцены подряд, 16.6 секунды. Ни один
тест этот каталог не читает — и это записано долгом **№211**, а не подразумевается.

## Сборка

```bash
node packages/cli/dist/bin/vpe.js build \
  --project examples/vertical-v1 --profile final --allow-tts
```

Пока дубли лежат в `voice/takes/`, сборка идёт БЕЗ СЕТИ вовсе: `--allow-tts` нужен только на
промахе. Пересъёмка голоса стоит денег и потому требует ДВУХ разрешений сразу
(`V-06`): `--allow-tts` и `ELEVENLABS_LIVE=1` в командной строке —

```bash
ELEVENLABS_LIVE=1 node packages/cli/dist/bin/vpe.js build \
  --project examples/vertical-v1 --profile final --allow-tts
```

Ключ и id голоса берутся ТОЛЬКО из окружения (`ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID`;
`.env` в корне репозитория подхватывается, но денежный флаг из него не читается). В
`project.yaml` лежит ИМЯ переменной, а не значение (CLAUDE.md §2).

Выход — `build/final.mp4` (каталог в `.gitignore`): 3 сегмента, ~~497 кадров, 16.567 с~~
**502 кадра (179 + 170 + 153), 16.733 с**, 1080×1920, ~~19.6~~ **19.2 МБ**. *(число кадров
сдвинул `E-07` третьей сценой; здесь оно ИЗМЕРЕНО прогоном `ENV-01`, 2026-08-31 — 1 мин 51 с,
«обращений к источнику 0». `E-02`, 2026-08-31: пересобрано с параллаксом во второй сцене — 1 мин
58 с, «обращений к источнику 0», 19.2 МБ.)*

**Тона в ролике нет.** `E-07` завёл `grade@1` и позвал его в трёх сценах; владелец посмотрел
и снял — «тон незаметен, готовые изображения буду давать уже обработанными» (`ENV-01`).
Шаблон и его записи гейта остались, вернуть тон стоит одной записи в `direction/`. Побочно
это видно в бюджете сцены: пик упал с 1773 до **135 мс/кадр** (`build/reports/budget.txt`).
*(`E-02`: параллакс во второй сцене поднял пик со 135 до **146 мс/кадр** — при пороге 250.)*

## Байты

В репозитории лежат только ЗАПИСИ (`assets/records/*.json`, `fonts/records/*.json`,
`store.lock`); байты живут в CAS `~/.vpe/store` (`store.path` проекта). На чистой машине их
надо положить туда заново по адресам из `provenance.origin.sourceUrl` — все четыре адреса
прямые и названы в записях поимённо. **Пятый файл адреса не имеет и иметь не может:** это
ПРОИЗВОДНЫЙ слой параллакса, его порождают из `mechanic` внешним инструментом, и рецепт лежит
в его записи (`derivedFrom.transform`), а не в `sourceUrl`.

## Что в нём стоит посмотреть

* **Сцена 2 идёт на 2.5D-параллаксе** (`E-02`, 2026-08-31): два слоя — сам снимок Хайна дальним
  планом и вырезка механика с насосом ближним, — расходящиеся за окно сцены на 59.8 px.
  Слои режет АВТОР внешним инструментом, у производного есть `derivedFrom`; движок глубину не
  оценивает и никогда не будет. Сцены 1 и 3 остались на `kenburns@1`.
  **Почему параллакс не на улице 1900, хотя задание называло её:** измерено (`E-02` §7.1) —
  инструмент класса u2net сегментирует ОДИН выделенный объект, а на Mulberry Street толпа без
  такового; три модели дали 0.1–0.2 % кадра. На снимке Хайна тот же `u2net` даёт 46.6 %.
* **Вертикаль берётся кадрированием, а не растяжением:** горизонтальный снимок 3840×2835
  доводится до 1080×1920 укладкой `cover` и ведётся Ken Burns по горизонтали.
* **По одному `captionEmphasis@1` на сцену.** Это не украшение: семейство шрифта полосы даёт
  КЛИП (долг **№207**), и без клипа в сегменте субтитры встали бы системной гарнитурой.
* **Полоса субтитров** — свойство трека, живёт в `composition/runtime.js`; числа её раскладки
  ПРЕДЛОЖЕНЫ `H-07` и ждут буквы владельца (долги **№125**, **№188**).
