# `examples/pompeii-30` — демо-ролик «Помпеи», 30 секунд

**Что это.** Настоящий проект движка, собираемый штатным `vpe build`, — не фикстура. Заведён
задачей [`DEMO-POMPEII`](../../docs/impl/DEMO-POMPEII/report.md) по заданию владельца от
2026-09-10. Ни один тест этот каталог не читает.

**Выход** — `build/final.mp4` (каталог в `.gitignore`): 3 сегмента, **877 кадров, 29.233 с**,
1080×1920, 28.0 МБ. Три сцены: извержение, раскопанный город, гипсовый слепок.

## Сборка

```bash
node packages/cli/dist/bin/vpe.js build \
  --project examples/pompeii-30 --profile final
```

Дубли лежат в `voice/takes/` — сборка идёт БЕЗ СЕТИ вовсе. Пересъёмка голоса стоит денег и
требует ДВУХ разрешений сразу (`V-06`): `--allow-tts` и `ELEVENLABS_LIVE=1` в командной строке.
Ключ и id голоса берутся ТОЛЬКО из окружения (`ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID`);
в `project.yaml` лежит ИМЯ переменной, а не значение (CLAUDE.md §2).

**Профиль `draftHalf` для просмотра НЕ ГОДИТСЯ** — долг **№265**: на нём в кадр попадает только
левый верхний квадрант композиции, а полоса субтитров пропадает целиком. Смотреть — только
`final`.

## Чего в ролике НЕТ, и это решения, а не пропуски

* **Музыки и звуковых эффектов.** Микса в v1 нет: музыка едет данными (`CP-05`), `mixSaturating`
  в аудио-зоне не зовётся, дорожка = речь + тишины движка. Решение владельца 2026-09-10 — «без
  музыки, только голос». Вернуть подложку будет стоить одной записи в `direction/` — после `X-02`.
* **Субтитров без плашки и без тени, с красным активным словом.** Оформление полосы — свойство
  канала (`composition/runtime.js`, долги №188/№125), правка сдвигает `bundleHash` и требует
  пересъёмки гейтов всех семи шаблонов по **V13**. Решение владельца — оставить как умеет движок.
  Разбор — [отчёт задачи](../../docs/impl/DEMO-POMPEII/report.md) §2.

## Что стоит посмотреть

* **Кадрирование сцен 2 и 3 идёт СВОИМИ числами поверх пресетов** — у отпечатков Соммера по краю
  напечатана подпись мастерской, и пресетные значения оставляли её в кадре. Разбор — §5 отчёта.
* **Вспышка `flash@1` на бите `plaster`** — единственное место, где ролик прибавляет голос.
* **Пословная эмфаза** видна на слове после `[emph]` и на активном слове полосы.
